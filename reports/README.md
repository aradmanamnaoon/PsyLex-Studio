# Dictionary extraction audit

`lexicon_audit.csv` is a reproducible **candidate-review queue** generated by:

```bash
python scripts/audit_lexicon.py --output reports/lexicon_audit.csv
```

The supplied documents yielded 20,157 candidate entries (19,168 from source A, 989 from source B).

Overlapping flags at extraction time include 2,578 low-score candidates, 801 Persian cells containing unexpected Latin words, 552 entries with unbalanced parentheses, 141 English cells with Persian letters, and 131 very short Persian fields.

A flag means **needs review**, not automatically incorrect. Unflagged entries are not automatically correct.
Do not use the raw dictionary index as a certified clinical vocabulary.
